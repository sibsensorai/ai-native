# Как добавить общий скилл на платформу «Сибсенсор AI»

Общие навыки компании лежат в этом репозитории (`sibsensorai/ai-native`, папка `skills/`)
и раздаются всем сотрудникам через marketplace **`company-agent-skills`**, который уже
подключён в Claude Code у всей команды.

## Два пути

### 1) Для любого сотрудника (без техники)
1. Реши рабочую задачу вместе с ИИ-помощником прямо в чате.
2. Попроси его: **«Упакуй это в скилл»** — он соберёт черновик (`SKILL.md` + `skill.yaml`).
3. Передай черновик **куратору скиллов** (ИТ) — он опубликует его на платформу.

### 2) Для куратора (публикация)
1. Создай папку навыка `skills/<имя-скилла>/`:
   ```
   skills/<имя-скилла>/
     SKILL.md     — что и как делает агент: когда применять, шаги, правила, чего нельзя
     skill.yaml   — паспорт навыка: имя, версия, совместимые агенты, нужные доступы
     references/  — вспомогательные материалы (необязательно)
   ```
   За образец бери `skills/sibsensor-kontrol-poruchenii/` или `skills/editorial-style/`.
2. Добавь навык в пакет в `agent-platform/skill-packs.json`
   (в список `skills` нужного пакета, например `sibsensor-pilot`).
3. Опубликуй **одной командой** из корня репозитория:
   - Windows:  `./publish-skill.ps1 "добавил скилл …"`
   - Mac/Linux: `./publish-skill.sh "добавил скилл …"`

   Скрипт сам: проверит скиллы → соберёт плагины → проверит сборку → закоммитит и запушит в `main`.

## Как коллеги получат новый скилл
В Claude Code: обновить marketplace `company-agent-skills` и обновить/переустановить
плагин (`/plugin` → вкладка **Code** → `company-agent-skills`).

## Правила
- Не клади в скиллы пароли, токены, ключи и персональные данные.
- Каждый упакованный скилл обязан содержать в `SKILL.md` блок телеметрии
  `gateway-skill-telemetry:v1` (см. примеры у готовых скиллов).
- Один скилл — одно понятное действие. Длинные справочные материалы выноси в `references/`.

## Кто может публиковать
Публиковать может тот, у кого есть доступ на запись в репозиторий `sibsensorai/ai-native`
(GitHub → Settings → Collaborators). Остальные присылают черновики куратору.
