# Подключение к «Сибсенсор AI» — за 3 минуты

Нужна только рабочая почта **`имя@sibsensor.com`**. Делай по шагам.

---

## Шаг 1. Установи приложение Claude
1. Открой: **claude.ai/download** → скачай для своей системы (Windows/Mac) → установи.
2. Запусти и войди в аккаунт Claude (нет аккаунта — заведи на `claude.ai`, бесплатно).

## Шаг 2. Вставь это в Claude — он настроится сам
1. В приложении открой вкладку **Code**.
2. **Скопируй весь текст из рамки ниже, вставь в чат и отправь.** Claude сам всё настроит.

> ```
> Ты — помощник в Claude Code. Настрой меня на корпоративное AI-ядро «Сибсенсор».
> Сделай ровно это и ничего больше:
>
> 1. Открой (или создай, если его нет) файл ~/.claude/settings.json.
> 2. Аккуратно добавь в него, НЕ удаляя и не меняя ничего остального:
>    - в объект "extraKnownMarketplaces" ключ "company-agent-skills" со значением:
>      { "source": { "source": "git", "url": "https://github.com/sibsensorai/ai-native.git" } }
>    - в объект "enabledPlugins" ключи:
>      "gateway-mcp@company-agent-skills": true
>      "sibsensor-pilot@company-agent-skills": true
>    Если каких-то объектов нет — создай их. Сохрани корректный JSON.
> 3. Покажи итоговый файл и напиши мне: "Полностью закрой и снова открой Claude Code,
>    затем задай любой рабочий вопрос, нажми «Войти через Яндекс» и войди рабочей почтой @sibsensor.com".
> ```

## Шаг 3. Перезапусти и войди
1. **Полностью закрой и снова открой** приложение Claude.
2. Во вкладке **Code** вставь в чат эту фразу и отправь:

> ```
> Подключись к корпоративному ядру «Сибсенсор» и покажи, кто я на ядре.
> ```

3. Claude обратится к ядру — откроется окно браузера. Нажми **«Войти через Яндекс»**, войди рабочей почтой **`@sibsensor.com`**, подтверди.
4. В ответ Claude покажет твоё имя/почту на ядре — значит, подключение есть.

**Готово — ты на ядре. ✅** Общие навыки компании уже подключены.

---

## Если Claude ответил, что не может менять настройки
Тогда настрой одной командой. Открой **PowerShell**, вставь это целиком и нажми Enter:

```powershell
$dir = Join-Path $env:USERPROFILE ".claude"; New-Item -ItemType Directory -Force -Path $dir | Out-Null; $p = Join-Path $dir "settings.json"; if (Test-Path $p) { Write-Host "У тебя уже есть settings.json — попроси Claude настроить (Шаг 2), чтобы не затереть твои настройки." -ForegroundColor Yellow } else { @'
{
  "extraKnownMarketplaces": {
    "company-agent-skills": { "source": { "source": "git", "url": "https://github.com/sibsensorai/ai-native.git" } }
  },
  "enabledPlugins": {
    "gateway-mcp@company-agent-skills": true,
    "sibsensor-pilot@company-agent-skills": true
  }
}
'@ | Out-File -FilePath $p -Encoding utf8; Write-Host "Готово. Перезапусти Claude Code и войди рабочей почтой через Яндекс." -ForegroundColor Green }
```

Потом — **Шаг 3** (перезапустить и войти).

## Если что-то пошло не так
- Ошибка **«not allowed by Gateway policy»** — напиши в ИТ (Алексей Лукин / Иван Шелемба).
- Не открывается вход — проверь интернет; полностью перезапусти приложение.
- Любая заминка — скриншот в ИТ, разберёмся.
